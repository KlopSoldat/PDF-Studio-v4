# PDF Studio

Бесплатный онлайн-редактор PDF, который работает целиком в браузере.
Без серверов, без регистрации, без ограничений на размер файла.

## Что умеет

**Редактирование страниц**
Удаляйте ненужные страницы, меняйте их порядок перетаскиванием,
поворачивайте, выделяйте сразу несколько. Отмена и повтор
изменений — привычным Ctrl+Z / Ctrl+Shift+Z.

**Аннотации**
Добавляйте текст с настройкой шрифта, размера, цвета и выравнивания.
Рисуйте поверх документа: прямоугольники, эллипсы, линии, стрелки,
маркер, карандаш от руки. Всё двигается и удаляется одним нажатием.

**Организация**
Объединяйте несколько PDF в один, извлекайте нужные страницы
по диапазону, разбивайте документы на части или отдельные страницы.
Раскладывайте несколько страниц на одном листе (N-up) для печати.

**Конвертация**
PDF → PNG/JPEG в высоком разрешении с настройкой DPI.
Изображения → PDF с автоматической подгонкой под А4 или Letter.

**Оптимизация**
Сжимайте тяжёлые документы, добавляйте водяные знаки и нумерацию
страниц, редактируйте метаданные (заголовок, автор, тема).

**Дополнительно**
Поиск по тексту с подсветкой совпадений, извлечение всего текста
в .txt, поиск и удаление пустых страниц, извлечение всех картинок
из документа одним архивом.

## Почему PDF Studio

**Приватность.** Файлы не отправляются на сервер — вся обработка
происходит в вашем браузере. Закройте вкладку — и документ исчезнет,
не останется ни в кэше, ни в облаке.

**Без регистрации.** Открыли сайт — работаете. Никаких аккаунтов,
email-адресов и подтверждений.

**Бесплатно и без ограничений.** Нет лимитов на размер файла,
количество операций или функции. Всё, что можно сделать — доступно сразу.

**Работает офлайн.** После первой загрузки страницы приложение
продолжает работать даже без интернета.

## Технологии

Приложение построено на открытых библиотеках:
- **pdf-lib** — создание и модификация PDF
- **pdf.js** — рендеринг страниц для предпросмотра
- **JSZip** — упаковка результатов в архивы

Никакого бэкенда, никакой базы данных, никаких сторонних сервисов.
